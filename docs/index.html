日本語

「縦書き for Google ドキュメント」（以下「本拡張機能」）は、Google ドキュメントの文書を縦書き・原稿用紙の形式でサイドパネルに表示する Chrome 拡張機能です。本ポリシーは、本拡張機能が扱う情報と、その使い方を説明します。

提供者: ロケット団合同会社（Rocket Dang LLC）

要点

  • 文書の内容は、お使いのブラウザの中だけで処理します。提供者のサーバーや第三者へ送信しません。
  • アクセス解析、広告、トラッキングは一切行いません。
  • 保存するのは、画面の設定（用紙の種類・書体など）だけです。文書の内容は保存しません。

本拡張機能が読み取る情報

情報目的取り扱い
開いている Google ドキュメントの本文と文書名縦書きで表示するためブラウザ内のメモリ上でのみ処理し、保存・送信しません。サイドパネルを閉じるか、別の文書に移ると破棄されます
Google ドキュメント上でキー入力・貼り付けなどの操作が「あった」という事実文書の更新を検知して、縦書き表示を最新にするためどのキーが押されたか、何が入力されたかは読み取りません。操作があったことだけを使います
文書のカーソルの位置（何ページ目の、どの高さにあるか）、カーソルのある行とその上下の行の文面、ページの大きさ編集している場所を縦書きの画面にも表示するため。また、縦書きの画面で選んだ場所へ文書の表示位置を合わせるためブラウザ内で使うだけで、保存・送信しません

文書の本文は、お使いの Google アカウントでログインしているブラウザの権限で、その文書を開いているタブから docs.google.com に対して取得します（Google ドキュメントの「HTML としてダウンロード」と同じ仕組みです）。本拡張機能は文書を読み取るだけで、変更しません。縦書きの画面で場所を選んだときは、Google ドキュメントの表示位置（スクロール）だけを動かします。

保存する情報

次の画面設定を、お使いのブラウザの拡張機能用の保存領域（chrome.storage.local）に保存します。ブラウザの外には出ません。拡張機能を削除すると、これらも削除されます。

  • 用紙の種類、1行の字数、1枚の行数
  • 書体、用紙の色、表示サイズ
  • 罫線・ルビ・縦中横・自動スクロールなどのオン／オフ

外部への通信

本拡張機能が通信するのは、文書を取得するための docs.google.com（Google）だけです。提供者のサーバーは存在せず、本拡張機能から提供者や第三者へ情報を送ることはありません。

権限について

権限使う理由
サイドパネル（sidePanel）縦書き表示を、Google ドキュメントの横のサイドパネルに出すため
ストレージ（storage）画面設定を保存するため
スクリプトの挿入（scripting）拡張機能をインストールする前から開いていた Google ドキュメントのタブにも、再読み込みなしで対応するため
docs.google.com/document/* へのアクセス開いている文書の本文を取得し、操作の有無を検知するため

第三者への提供・販売

利用者の情報を第三者に販売、貸与、提供することはありません。広告の目的や、信用の判断、融資の目的で利用することもありません。

ポリシーの変更

本ポリシーを変更するときは、このページを更新し、更新日を改めます。

English

"縦書き for Google ドキュメント" (the "Extension") is a Chrome extension that shows a Google Docs document in vertical Japanese writing (tategaki) on manuscript paper in the side panel. This policy explains what information the Extension handles and how it is used.

Provider: Rocket Dang LLC (ロケット団合同会社)

Summary

  • Document content is processed only inside your browser. It is never sent to the provider's servers or to any third party.
  • There is no analytics, advertising or tracking.
  • The only thing stored is your display settings (paper type, font, etc.). Document content is not stored.

What the Extension reads

InformationPurposeHandling
Text and title of the Google Docs document you have openTo display it in vertical writingProcessed in browser memory only; never stored or sent. Discarded when you close the side panel or switch to another document
The fact that a key press, paste, etc. happened on the Google Docs pageTo detect that the document changed and keep the view up to dateThe Extension does not read which keys were pressed or what was typed; it uses only the fact that an action happened
The position of the document cursor (which page, and how far down the page), the text of the line the cursor is on and the lines just above and below it, and the page sizeTo show the place you are editing in the vertical view, and to scroll the document to a location picked in the vertical viewUsed inside the browser only; never stored or sent

The document text is fetched from docs.google.com by the tab that has the document open, using your browser's existing Google sign-in (the same mechanism as Google Docs' "Download as HTML"). The Extension only reads the document and never modifies it. When you pick a location in the vertical view, it only scrolls the Google Docs view to that location.

What is stored

The following display settings are stored in the browser's extension storage (chrome.storage.local). They never leave your browser and are removed when you uninstall the Extension.

  • Paper type, characters per line, lines per sheet
  • Font, paper color, display size
  • On/off switches such as grid lines, ruby, tate-chu-yoko and auto-scroll

Network access

The only server the Extension talks to is docs.google.com (Google), to fetch the document. The provider operates no server for this Extension, and the Extension sends nothing to the provider or to any third party.
