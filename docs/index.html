日本語

「縦書き for Google ドキュメント」（以下「本拡張機能」）は、Google ドキュメントの文書を縦書き・原稿用紙の形式でサイドパネルに表示し、縦書きのまま書くこともできる Chrome 拡張機能です。本ポリシーは、本拡張機能が扱う情報と、その使い方を説明します。

提供者: ロケット団合同会社（Rocket Dang LLC）

要点

  • 文書の内容は、お使いのブラウザの中だけで処理します。提供者のサーバーや第三者へ送信しません。通信の相手は Google だけです。
  • アクセス解析、広告、トラッキングは一切行いません。
  • 保存するのは、画面の設定（用紙の種類・書体など）だけです。文書の内容は保存しません。
  • 縦書きの画面で書く機能（執筆モード）を使うときだけ、Google アカウントの許可を求めます。読み書きできるのは、あなたが選んだ文書だけです。

本拡張機能が読み取る情報

情報目的取り扱い
開いている Google ドキュメントの本文と文書名縦書きで表示するためブラウザ内のメモリ上でのみ処理し、保存・送信しません。サイドパネルを閉じるか、別の文書に移ると破棄されます
Google ドキュメント上でキー入力・貼り付けなどの操作が「あった」という事実文書の更新を検知して、縦書き表示を最新にするためどのキーが押されたか、何が入力されたかは読み取りません。操作があったことだけを使います
文書のカーソルの位置（何ページ目の、どの高さにあるか）、カーソルのある行とその上下の行の文面、ページの大きさ編集している場所を縦書きの画面にも表示するため。また、縦書きの画面で選んだ場所へ文書の表示位置を合わせるためブラウザ内で使うだけで、保存・送信しません

文書の本文は、お使いの Google アカウントでログインしているブラウザの権限で、その文書を開いているタブから docs.google.com に対して取得します（Google ドキュメントの「HTML としてダウンロード」と同じ仕組みです）。表示するだけのとき（表示モード）は、文書を読み取るだけで、変更しません。縦書きの画面で場所を選んだときは、Google ドキュメントの表示位置（スクロール）を動かし、その場所に目印を表示するだけです。

執筆モード（縦書きの画面で書く機能）と Google アカウントの情報

執筆モードは、あなたが「執筆」ボタンを押したときにだけ働きます。使わなければ、Google アカウントの許可を求めることはありません。

情報目的取り扱い
Google アカウントの許可（アクセストークン）。範囲は「このアプリで使用する特定の Google ドライブのファイルのみ」（drive.file）あなたが選んだ文書を、Google ドキュメントの API で読み書きするためブラウザを閉じるまでの一時的な保存領域（chrome.storage.session）にだけ置きます。提供者には送りません。メールアドレスや氏名などのアカウント情報は取得しません
あなたが選んだ文書の本文と書式縦書きの画面に表示し、あなたが入力・削除した内容と、見出しの設定を、その文書に保存するためブラウザ内のメモリ上でのみ処理します。送り先は Google（docs.googleapis.com）だけです

読み書きできるのは、Google の「ファイルを選ぶ画面」であなたが選んだ文書だけです。ほかの文書やファイルには、本拡張機能からはアクセスできません。本拡張機能が文書に行う変更は、あなたが縦書きの画面で行った入力・削除と、段落を見出しにする・標準テキストに戻す操作だけです。

「ファイルを選ぶ画面」は、提供者の公開ページ（nishigaki-source.github.io/tategaki-support/picker.html）の上に、Google が提供する部品（Google Picker）で表示します。このページは、文書を選んでもらうためだけのもので、アクセストークンや文書の内容を保存・送信しません。

許可は、Google アカウントの「サードパーティのアプリとサービス」から、いつでも取り消せます。

Google のユーザーデータの取り扱い: 本拡張機能による、Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。Google API から受け取った情報は、上に書いた機能を提供するためだけに使い、広告には使わず、第三者に渡さず、人が読むこともありません。

保存する情報

次の画面設定を、お使いのブラウザの拡張機能用の保存領域（chrome.storage.local）に保存します。ブラウザの外には出ません。拡張機能を削除すると、これらも削除されます。

  • 用紙の種類、1行の字数、1枚の行数
  • 書体、用紙の色、表示サイズ
  • 罫線・ルビ・縦中横・自動スクロールなどのオン／オフ

外部への通信

本拡張機能が通信する相手は、Google だけです。文書を取得するための docs.google.com と、執筆モードを使うときの accounts.google.com（許可）・docs.googleapis.com（文書の読み書き）・「ファイルを選ぶ画面」です。提供者のサーバーは存在せず、本拡張機能から提供者や第三者へ情報を送ることはありません。

権限について

権限使う理由
サイドパネル（sidePanel）縦書き表示を、Google ドキュメントの横のサイドパネルに出すため
ストレージ（storage）画面設定を保存するため
スクリプトの挿入（scripting）拡張機能をインストールする前から開いていた Google ドキュメントのタブにも、再読み込みなしで対応するため
docs.google.com/document/* へのアクセス開いている文書の本文を取得し、操作の有無とカーソルの場所を知るため。また、縦書きの画面で選んだ場所へ表示位置を動かすため
ID（identity）執筆モードで、Google アカウントの許可の画面を表示するため

第三者への提供・販売

利用者の情報を第三者に販売、貸与、提供することはありません。広告の目的や、信用の判断、融資の目的で利用することもありません。

ポリシーの変更

本ポリシーを変更するときは、このページを更新し、更新日を改めます。

English

"縦書き for Google ドキュメント" (the "Extension") is a Chrome extension that shows a Google Docs document in vertical Japanese writing (tategaki) on manuscript paper in the side panel, and also lets you write in that vertical view. This policy explains what information the Extension handles and how it is used.

Provider: Rocket Dang LLC (ロケット団合同会社)

Summary

  • Document content is processed only inside your browser. It is never sent to the provider's servers or to any third party. The Extension talks only to Google.
  • There is no analytics, advertising or tracking.
  • The only thing stored is your display settings (paper type, font, etc.). Document content is not stored.
  • Google account authorization is requested only when you use the writing feature (Write mode). The Extension can read and write only the documents you pick.

What the Extension reads

The document text is fetched from docs.google.com by the tab that has the document open, using your browser's existing Google sign-in (the same mechanism as Google Docs' "Download as HTML"). When you only view a document (View mode), the Extension only reads it and never modifies it. When you pick a location in the vertical view, it only scrolls the Google Docs view to that location and shows a marker there.

Write mode and Google account data

Write mode runs only after you press the "執筆" (Write) button. If you never use it, the Extension never asks for Google account authorization.

The Extension can read and write only the documents you pick in Google's file picker. It cannot access any other document or file. The only changes it makes to a document are the text you type or delete in the vertical view, and turning a paragraph into a heading or back into normal text.

The file picker is shown with Google's own component (Google Picker) on the provider's public page (nishigaki-source.github.io/tategaki-support/picker.html). That page exists only to let you pick the document; it does not store or send the access token or any document content.

You can revoke the authorization at any time from "Third-party apps & services" in your Google account.

Google user data: The Extension's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Information received from Google APIs is used only to provide the features described above. It is not used for advertising, is not transferred to third parties, and is not read by humans.

What is stored

The following display settings are stored in the browser's extension storage (chrome.storage.local). They never leave your browser and are removed when you uninstall the Extension.

  • Paper type, characters per line, lines per sheet
  • Font, paper color, display size
  • On/off switches such as grid lines, ruby, tate-chu-yoko and auto-scroll

Network access

The Extension talks only to Google: docs.google.com to fetch the document, and, when you use Write mode, accounts.google.com (authorization), docs.googleapis.com (reading and writing the document) and the file picker. The provider operates no server for this Extension, and the Extension sends nothing to the provider or to any third party.
